Cara Install di Android

1

Buka Menu Browser

Buka aplikasi ini menggunakan Chrome, lalu ketuk ikon tiga titik di pojok kanan atas layar.

2

Pilih "Pasang Aplikasi"

Gulir ke bawah dan pilih opsi "Pasang Aplikasi" atau "Add to Home Screen".

3

Konfirmasi Install

Ketuk "Pasang" untuk mengonfirmasi. Aplikasi akan muncul di layar utama.

Cara Install di iPhone / iPad

1

Buka Menu Share

Buka aplikasi ini menggunakan Safari, lalu ketuk ikon Share di pojok bawah layar.

2

Pilih "Tambah ke Layar Utama"

Gulir ke bawah dan pilih opsi "Tambah ke Layar Utama".

3

Selesai

Ketuk "Tambah" di pojok kanan atas. Aplikasi akan siap di layar utama.
