# 🚀 Aplikasi E-Kinerja Harian - Solusi Modern untuk Pelaporan Kerja Harian

![Logo Aplikasi](https://ekinerja-pro.sneijderlino.workers.dev/logo-link.png)

**Versi Terbaru: 2.1.0** - Update Dashboard Android & Perbaikan UI

Aplikasi web inovatif yang dirancang khusus untuk memudahkan pegawai dalam membuat, mengelola, dan mengekspor laporan kerja harian ke format PDF. Dengan antarmuka yang elegan dan fitur canggih, aplikasi ini mengubah proses pelaporan manual menjadi digital dan efisien.

## 🌟 Kelebihan Aplikasi E-Kinerja Harian

### ⚡ **Performa Tinggi & Offline-First**

- **Aplikasi Web Progresif (PWA)**: Bisa diinstall seperti aplikasi native
- **Offline Capable**: Berfungsi tanpa koneksi internet setelah aktivasi
- **Penyimpanan Lokal**: Data tersimpan aman di browser Anda

### 🔒 **Keamanan & Lisensi**

- **Aktivasi Perangkat**: Sistem lisensi berbasis UUID untuk keamanan maksimal
- **Data Privat**: Tidak ada server eksternal, semua data lokal
- **Enkripsi Otomatis**: Data tersimpan dengan aman

### 📊 **Fitur Canggih**

- **Dashboard Interaktif**: Statistik laporan dengan chart visual
- **Preview Real-time**: Lihat hasil laporan sebelum ekspor
- **Filter & Pencarian**: Temukan laporan dengan mudah
- **Upload Media**: Tambahkan logo instansi dan foto kegiatan
- **Ekspor PDF Premium**: Kualitas tinggi dengan html2pdf.js

### 🎯 **User Experience Unggul**

- **Interface Modern**: Desain gelap elegan dengan animasi smooth
- **Mobile Responsive**: Optimal di desktop, tablet, dan smartphone
- **Intuitif**: Mudah digunakan bahkan untuk pemula
- **Customizable**: Sesuaikan kop instansi dan identitas

### 💼 **Efisiensi Kerja**

- **Otomatisasi**: Kop dan identitas tersimpan otomatis
- **Template Siap Pakai**: Format laporan standar
- **Waktu Real**: Input cepat dengan validasi otomatis
- **Arsip Digital**: Simpan ratusan laporan tanpa batas

## 🚀 Mulai Gunakan Sekarang!

### Persyaratan Sistem

- Browser modern (Chrome, Firefox, Safari, Edge)
- Dukungan localStorage dan File API
- Tidak memerlukan instalasi software tambahan

### Langkah Instalasi

1. **Unduh Repository**: Clone atau download dari GitHub
2. **Buka di Browser**: Double-click `index.html`
3. **Aktivasi Lisensi**: Salin UUID perangkat dan dapatkan kunci dari admin
4. **Mulai Input**: Isi data instansi dan mulai buat laporan
